## 1. Overview & Core Concept

Daycraft's Offline AI Companion currently provides static text summaries that disappear when navigating away. This upgrade transforms the companion into an **action-oriented, stateful workspace assistant** that reasons across local tasks, calendar blocks, goals, projects, habits, focus sessions, notes, study subjects, journal entries, and wellness logs—and turns insights into **one-click executable actions** right inside the conversation stream.

Every recommendation or schedule generated by the Offline AI is presented as a rich interactive proposal card that previews the exact changes before mutating the local database, giving the user complete control and transparency.

## 2. User Experience & Visual Design

### Aesthetic & Spatial Architecture
- **Calm Forest-Green Editorial Identity**: Preserves Daycraft's signature warm tactile surfaces (`--bg-surface`, `--bg-surface-elevated`), subtle 1px hairline borders (`--border-subtle`), `--accent` forest-green primary actions, and `tabular-nums` alignment for all durations, time slots, percentages, and capacity metrics.
- **Zero-Pill Discipline for Static Metadata**: Analytical tags, timestamps, and tool audit trails use clean monospace or uppercase tracked labels (`11px`, `tabular-nums`) rather than pill-shaped badges, reserving interactive rounded buttons strictly for clickable mode selectors, quick-prompt chips, and action triggers.
- **Two-Column Studio Layout**:
  - **Left Collapsible Thread Rail**: Displays persistent conversation threads ordered by recent activity, with controls to start a new chat, switch threads, rename a thread inline, or delete old conversations.
  - **Main Companion Viewport**:
    1. **Header & Mode Switcher Bar**: Houses the local model status, privacy-permission drawer toggle, and a 4-way segmented mode bar (*Daily Planner*, *Triage & Timebox*, *Socratic & Insights Coach*, *Study Quizzer*) that dynamically adapts the assistant's reasoning focus and contextual quick-prompt starters.
    2. **Interactive Conversation Stream**: Renders markdown responses alongside embedded **Interactive Action Cards** and a bottom message toolbar for **Save to Notes** and **Save to Journal**.
    3. **Natural-Language Composer**: Supports conversational queries, slash-style or natural-language task/habit creation, and contextual quick-action triggers.

### Interactive Action Cards in Chat
Instead of plain bullet lists, assistant messages can attach structured interactive cards:
- **Timebox Schedule Proposal Card**: Shows proposed time blocks (`09:00–09:45 · High Priority Task`) mapped into today's open calendar windows (`07:00–21:30`), with checkboxes to toggle individual blocks and an **Apply Schedule to Calendar** button.
- **Goal & Project Decomposer Card**: Lists concrete, domain-tailored milestone tasks with editable/selectable checkboxes, estimated minutes, and priority, plus a **Create Selected Tasks** button linked directly to the parent Goal or Project.
- **Overdue Triage Card**: Groups overdue items into *Do Today (Top 3)*, *Rollover to Tomorrow*, and *Move to Inbox*, with a single **Execute Triage Plan** button and inline checkboxes to mark tasks done immediately.
- **Natural-Language Creation Card**: When the user types a command like *"Create a high priority task to review architecture docs tomorrow at 3pm for 45m"* or *"Add daily habit Meditate 15m"*, renders a live preview of the parsed fields (title, due date, time, duration, priority, or habit frequency) with a one-click **Confirm & Create** button.
- **Correlation & Burnout Radar Card**: Displays clean side-by-side tabular comparisons (e.g., average mood & focus minutes on days habits are completed vs. skipped; scheduled task minutes vs. historical daily focus capacity) with a one-click **Auto-Balance Overloaded Day** action when capacity exceeds 100%.
- **Socratic Reflection & Study Flashcard Cards**: Interactive flip-to-reveal flashcards generated from local Notes and Study Subjects (with *Got It* / *Review Again* self-grading), and personalized Socratic journal prompts with an inline **Write Reflection to Today's Journal** composer.

## 3. Key Product Decisions & Trade-Offs

- **Proposal-Then-Confirm Execution Model**: Rather than silently mutating tasks or calendar blocks when a user asks to plan their day or triage overdue work, the engine generates a deterministic `AIActionProposal` attached to the assistant message. Clicking the confirmation button executes the mutation through the local database manager, records the applied state on the message so it cannot be accidentally double-applied, and triggers gamification XP where appropriate.
- **Strict Opt-In Privacy Enforcement**: Cross-domain tools (such as Habit/Focus/Mood correlations and Socratic Journal prompts) check the user's granular `aiPermissions` flags first. If `journal` or `wellness` access is disabled, the assistant gracefully explains which toggle in the Privacy Bar unlocks deeper correlation insights while still computing focus-and-habit correlations from permitted domains.
- **Local-First Multi-Thread Persistence**: Conversation threads and messages are stored directly in the local database snapshot (`aiConversations` and `aiMessages`), ensuring full compatibility with offline JSON backup and restore without external dependencies.

### Data Model & Engine Extensions
1. **Conversation & Action Schema**:
   - Extend `AIConversation` with `mode` (`'planner' | 'triage' | 'coach' | 'quizzer'`) and `pinned` state.
   - Extend `AIMessage` with optional `mode` and structured `actionProposals` (supporting `timebox_plan`, `task_decomposition`, `overdue_triage`, `quick_create`, `socratic_prompts`, `study_quiz`, and `capacity_radar` payloads, each tracking its `applied` status).
2. **Local Analytics & Action Proposal Runner**:
   - **Timebox Planner**: Scans unscheduled due/high-priority tasks and matches them against open slots between `07:00` and `21:30` around existing calendar events and time blocks.
   - **Goal & Project Decomposer**: Inspects active goals and projects, generating context-aware milestone tasks with estimated durations and priorities.
   - **Correlation & Capacity Radar Engine**: Computes multi-day intersections between habit logs, focus session minutes, journal mood/energy ratings, and scheduled task minutes vs. historical focus capacity.
   - **Study Quiz & Socratic Generator**: Extracts structured Q&A flashcards from local notes/study topics and synthesizes personalized reflection questions from today's activity.
